## Amiga Music Preservation

4champ reaches AMP through its developer's own API, which is reserved for 4champ. For this app, API usage
policy and keys have to be agreed with the AMP staff directly. Until that is done the app contains no AMP
source, makes no requests to amp.dascene.net or 4champ.net, and stays strictly non-profit: no ads, no
tracking, no payments.
